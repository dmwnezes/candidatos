# Propostas às cegas — Presidência 2026

Site estático em que o visitante compara, tema a tema, as principais propostas de dois candidatos à Presidência **sem saber de quem é cada uma**. No fim, mostra com qual candidato ele mais se parece.

- `index.html` — página e lógica do teste.
- `propostas.js` — propostas resumidas por tema.

Fonte: Planos de Governo registrados no TSE (DivulgaCandContas). Os textos foram resumidos e neutralizados (sem nomes de programas, partidos ou pessoas).
